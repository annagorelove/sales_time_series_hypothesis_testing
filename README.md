## Статистический анализ продаж продуктовой линейки ##
### Цель проекта

Провести статистический анализ временных рядов продаж по брендам, проверить ключевые гипотезы о трендах, сезонности и взаимосвязях, и сформировать рекомендации для маркетинга, ассортимента и управления спросом.

### Проверяемые гипотезы и методы анализа

1. Тренд продаж во времени (тест Манна–Кендалла)

H₀: тренда нет
H₁: тренд существует

Для оценки монотонной тенденции использован тест Манна–Кендалла.
Из‑за большого объёма данных чтение выполнено через Dask, далее взята выборка 40%.

Результат:
Обнаружен убывающий тренд.
На уровне значимости 0.05 нулевая гипотеза отвергается → тренд статистически значим.

2. Линейная регрессия продаж во времени

H₀: линейной зависимости нет
H₁: линейная зависимость есть

Построена модель линейной регрессии и визуализирована линия тренда.

Результат:
На уровне значимости 0.05 нулевая гипотеза принята → линейной зависимости нет.
Продажи не растут и не падают линейно, динамика сложнее.

3. Сезонность продаж по месяцам (критерий Фридмана)

H₀: сезонные изменения одинаковы для всех брендов
H₁: сезонные изменения различаются

Использован критерий Фридмана для связанных выборок.
Данные агрегированы в широкую таблицу (бренды × месяцы).
Построена декомпозиция временного ряда.

Результат:
На уровне значимости 0.05 нулевая гипотеза отвергнута → сезонные различия между брендами есть.
Однако продукт не является ярко выраженно сезонным.

4. Корреляция продаж между брендами (Спирмен)

H₀: корреляции нет
H₁: корреляция есть

Использован коэффициент Спирмена.

Результат:
На уровне значимости 0.05 обнаружена положительная корреляция между брендами:

- 3 и 4
- 5 и 6

Это может означать:

- совместные покупки,
- схожее позиционирование,
- одинаковое влияние маркетинга.

### Ключевые выводы анализа

- Продажи имеют убывающий тренд.
- Линейной зависимости от времени нет — динамика нелинейная.
- Сезонность различается между брендами, но продукт не сезонный.
- Между отдельными брендами есть значимая корреляция.
- Спрос нестабилен, присутствуют колебания, требующие анализа причин.

### Рекомендации для бизнеса

1. Усилить маркетинг лидирующих брендов и расширить каналы продаж.
2. Оптимизировать слабые позиции или заменить их новыми продуктами.
3. Планировать производство с учётом выявленных колебаний спроса.
4. Контролировать прибыльность ассортимента и корректировать цены.
5. Использовать аналитику для удержания клиентов и роста повторных покупок.
6. Анализировать причины корреляций между брендами (совместные покупки, маркетинг).


Эти меры помогут выровнять спрос и снизить риски резких спадов.
